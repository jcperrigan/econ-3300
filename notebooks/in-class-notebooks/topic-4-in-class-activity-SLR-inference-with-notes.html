In-Class Activity: Inference in Simple Linear Regression

  • Learning goals
  • 1. Set up and inspect the data
  • 2. Compare the two groups
  • 3. Connect a binary regressor to group means
  • 4. Construct a hypothesis test by hand
  • 5. Test nonzero null hypotheses
  • 6. Construct confidence intervals
  • 7. Conventional versus unequal-variance inference
  • 8. Statistical significance and causal language
  • 9. Final synthesis
  • Optional extension: sampling variability

Learning goals

By the end of this activity, you should be able to:

  • explain why regression estimates vary across samples;
  • interpret a regression with a binary explanatory variable;
  • conduct hypothesis tests about zero and nonzero coefficient values;
  • construct and interpret confidence intervals;
  • connect a binary-regressor model to a difference in group means; and
  • compare conventional and unequal-variance standard errors.

3. Connect a binary regressor to group means

Consider the population model

\[ lwage_i=\beta_0+\beta_1 urban_i+u_i. \]

Under the zero conditional mean assumption,

\[ E(lwage_i\mid urban_i=0)=\beta_0 \]

and

\[ E(lwage_i\mid urban_i=1)=\beta_0+\beta_1. \]

So

\[ \beta_1=E(lwage_i\mid urban_i=1)-E(lwage_i\mid urban_i=0). \]

  1. Interpret \(\beta_0\) and \(\beta_1\) in this application.

\(\beta_0\) is mean log earnings among non-urban workers. \(\beta_1\) is urban mean log earnings minus non-urban mean log earnings.

4. Construct a hypothesis test by hand

Test

\[ H_0:\beta_1=0 \qquad \text{against} \qquad H_1:\beta_1\neq0. \]

Assuming equal population variances, the pooled variance and conventional standard error are

\[ s_p^2=\frac{(n_1-1)s_1^2+(n_0-1)s_0^2}{n_1+n_0-2} \]

and

\[ SE(\bar Y_1-\bar Y_0)= \sqrt{s_p^2\left(\frac{1}{n_1}+\frac{1}{n_0}\right)}. \]

urban_group <- wage2 |> filter(urban == 1)
nonurban_group <- wage2 |> filter(urban == 0)

n_1 <- nrow(urban_group)
n_0 <- nrow(nonurban_group)
mean_1 <- mean(urban_group$lwage)
mean_0 <- mean(nonurban_group$lwage)
var_1 <- var(urban_group$lwage)
var_0 <- var(nonurban_group$lwage)

mean_difference <- mean_1 - mean_0
pooled_variance <- ((n_1 - 1) * var_1 + (n_0 - 1) * var_0) /
  (n_1 + n_0 - 2)
conventional_se <- sqrt(pooled_variance * (1 / n_1 + 1 / n_0))
degrees_freedom <- n_1 + n_0 - 2
t_statistic <- mean_difference / conventional_se
p_value <- 2 * pt(-abs(t_statistic), df = degrees_freedom)

tibble(
  `Coefficient estimate` = mean_difference,
  `Standard error` = conventional_se,
  `t statistic` = t_statistic,
  `Degrees of freedom` = degrees_freedom,
  `p value` = p_value
) |>
  mutate(
    across(c(`Coefficient estimate`, `Standard error`, `t statistic`), ~ round(.x, 3)),
    `Degrees of freedom` = round(`Degrees of freedom`, 0),
    `p value` = if_else(
      `p value` < 0.001,
      "<0.001",
      format(round(`p value`, 3), nsmall = 3)
    )
  ) |>
  knitr::kable(
    caption = "Hand-calculated two-sided test of no urban–non-urban difference",
    align = c("r", "r", "r", "r", "r")
  ) |>
  kableExtra::kable_styling(full_width = FALSE, position = "left") |>
  kableExtra::row_spec(0, bold = TRUE)

  1. At \(\alpha=0.05\), what is your decision? State the conclusion in context without saying that you “accept” the null.

At \(\alpha=0.05\), reject the null hypothesis of equal population mean log earnings. The sample provides statistically significant evidence of a difference.

  1. Explain the p-value in context. Begin with “If the null hypothesis were true…”

If the null hypothesis were true, the p-value is the probability of obtaining a t-statistic at least as far from zero as the observed statistic, in either direction, through sampling variation under the model assumptions.

  1. Compare your estimate, standard error, t-statistic, and p-value with summary(urban_model).

The hand calculations match summary(urban_model) up to rounding because a binary-regressor OLS model with conventional standard errors is the pooled difference-in-means test.

5. Test nonzero null hypotheses

Test \(H_0:\beta_1=0.10\) and \(H_0:\beta_1=0.20\), using a two-sided alternative in each case.

# Calculate a t-statistic and two-sided p-value for each null value

    t_statistic = (mean_difference - beta_null) / conventional_se,
    p_value = 2 * pt(-abs(t_statistic), df = degrees_freedom),

7. Conventional versus unequal-variance inference

An unequal-variance standard error for the group difference is

\[ SE_{unequal}=\sqrt{\frac{s_1^2}{n_1}+\frac{s_0^2}{n_0}}. \]

unequal_se <- sqrt(var_1 / n_1 + var_0 / n_0)
welch_df <- (var_1 / n_1 + var_0 / n_0)^2 /
  ((var_1 / n_1)^2 / (n_1 - 1) + (var_0 / n_0)^2 / (n_0 - 1))
welch_t <- mean_difference / unequal_se
welch_p <- 2 * pt(-abs(welch_t), df = welch_df)

tibble(
  `Conventional standard error` = conventional_se,
  `Unequal-variance standard error` = unequal_se,
  `Welch t statistic` = welch_t,
  `Welch degrees of freedom` = welch_df,
  `Welch p value` = welch_p
) |>
  mutate(
    across(
      c(
        `Conventional standard error`,
        `Unequal-variance standard error`,
        `Welch t statistic`,
        `Welch degrees of freedom`
      ),
      ~ round(.x, 3)

    `Welch p value` = if_else(
      `Welch p value` < 0.001,

8. Statistical significance and causal language

  1. A classmate writes: “Living in an urban area causes monthly earnings to increase.” Rewrite the claim so it is supported by this analysis.

Supported statement: “Urban workers have higher average monthly earnings than non-urban workers in this sample,” followed by the estimated percentage difference.

  1. Name two factors that could affect earnings and be systematically different between urban and non-urban workers. What would leaving them out mean for \(E(u\mid urban)=0\)?

Examples include education, occupation, industry, experience, local price levels, and regional labor-market conditions. If an omitted factor affects earnings and differs systematically by urban status, \(E(u | urban) = 0\) fails and the coefficient may be biased.

  1. Is statistical significance the same as practical importance? What additional context would help you evaluate the size/ magnitude?

Statistical significance measures evidence against a null relative to sampling uncertainty. Practical importance requires context such as dollar earnings, local cost-of-living differences, and comparisons with other earnings gaps.

9. Final synthesis

In 4–6 sentences, summarize the estimated difference, uncertainty, hypothesis-test result, and one important limitation. Use percentage language and avoid causal language.

One possible response: Urban workers earn approximately 21% more per month than non-urban workers in this sample. The 95% interval corresponds to an exact percentage difference of approximately 14.1% to 28.3%. The test of no population difference is rejected at the 5% level. Unequal-variance inference can be compared with the conventional result. The analysis is associational because other differences between urban and non-urban workers may explain part of the gap.
